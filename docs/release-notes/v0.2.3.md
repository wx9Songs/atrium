Atrium on a phone behaves more like a phone app.

## What changed

- **The session list is home.** Back from a conversation used to land on the new-session page. On a phone the list is now the home screen: back, or a swipe from the left edge, returns to it.
- **Enter key.** On a touch screen Enter now makes a new line and the send button sends; on a computer Enter still sends and Shift+Enter makes a new line. "Enter key" in the ⋯ menu sets it to Auto, Send or New line (then Cmd/Ctrl+Enter sends). The phone keyboard's Enter key shows which it does.
- The keyboard shortcut list is left out of the menu on touch screens.

## Updating

Only the hub changed (the page is built into it): replace `atrium` on the server, restart it and reload open pages. Runners and the macOS app are as in 0.2.2 apart from the version number.

手机上的 Atrium 更像一个手机应用了。

- **会话列表就是主页**：以前从对话里点返回会落到新会话页面。现在手机上会话列表是主页，点返回或从左边缘往右滑都回到这里。
- **回车键**：触屏上回车换行、点发送按钮发送；电脑上仍是回车发送、Shift+回车换行。⋯ 菜单里的“回车键”可以设为自动、发送或换行（换行时 ⌘/Ctrl+回车发送）。手机键盘上的回车键会显示它的作用。
- 触屏设备上，菜单里不再显示键盘快捷键列表。
- **升级**：只有 hub 有变化（页面内置在里面）：替换服务器上的 `atrium`、重启，然后刷新已打开的页面。runner 和 macOS 应用除版本号外与 0.2.2 相同。
