Editing a message or trying an answer again now stays in the same session.

## What changed

- **Edit and try again, in place.** Editing one of your messages or trying a reply again used to fork a new session each time. Now the session itself goes back to just before that message and continues from there, the way Claude Code's own rewind does: same session id, no extra entry in the sidebar, and `claude --resume` in a terminal picks up the new version. The turns it replaced are folded under a "rewritten here" mark and can be opened again.
  - The first message of a session has nothing before it to go back to, so rewriting that one still starts a new session.
  - Files are not rolled back: whatever the replaced turns changed in the folder stays changed.
  - "Fork" and side chat are unchanged: they still make a new session and leave the original alone.
  - Codex sessions cannot be cut in the middle, so this is for Claude Code sessions, as before.
- **A lapsed sign-in no longer breaks a session.** On a machine with two Claude config directories (for example `~/.claude` used by Claude Desktop's remote sessions and another one used by the terminal), a session recorded in the directory whose sign-in had expired failed with "OAuth session expired and could not be refreshed". The runner now checks whether a directory's sign-in can still be used, not just whether its file exists, and resumes the session from the directory that is signed in.
- **Resending a message that never went out.** If the last message failed before it reached the machine, editing or retrying it now simply sends it, instead of failing with "message not found".

## Updating

- **Hub and runners both need this version.** Replace `atrium` on the server and `atrium-runner` on each machine, and restart them. Until a machine's runner is updated, editing there keeps forking a new session as before. On one computer: unpack the new archive and run `./scripts/local-install.sh install` again; your config and sign-in stay.
- **macOS app**: nothing changed in the app itself; `Atrium-0.1.2.dmg` differs from 0.1.1 only in its version number. It is still not signed with an Apple Developer ID; see the README for how to open it.

Downloads are the same set as before: one archive per system, the app's `.dmg`, and `SHA256SUMS`.

编辑消息、重新生成回复，现在都留在同一个会话里。

- **原地编辑和重新生成**：以前每次编辑自己的消息或重新生成回复，都会分叉出一个新会话。现在会话本身回到那条消息之前重新继续，和 Claude Code 自己的"回退"是同一个做法：会话 ID 不变，侧栏里不会多出一项，之后在终端里 `claude --resume` 接上的也是新版本。被替换的几轮对话折叠在"这里改写过"的标记下面，可以再点开看。
  - 会话的第一条消息前面没有可以回到的位置，改写它仍然会新开一个会话。
  - 文件不会回滚：被替换的那几轮在目录里做过的改动仍然在。
  - "分叉"和边聊不变：仍然生成新会话，原会话保持原样。
  - Codex 会话不能从中间截断，所以和以前一样，只对 Claude Code 会话提供。
- **过期的登录不再让会话失败**：一台机器上有两个 Claude 配置目录时（比如 Claude 桌面版远程会话用的 `~/.claude`，和终端用的另一个目录），记录在登录已过期的那个目录里的会话，续接时会报 "OAuth session expired and could not be refreshed"。现在 runner 会检查目录里的登录是否还能用，而不只是看文件在不在，并改从已登录的目录续接。
- **重发没发出去的消息**：最后一条消息如果在到达机器之前就失败了，编辑或重试它现在会直接发送，不再报"找不到那条消息"。
- **升级**：hub 和 runner 都要换成这一版并重启。某台机器的 runner 没更新之前，在那台机器上编辑仍会像以前一样分叉出新会话。单机安装解压新压缩包后再跑一次 `./scripts/local-install.sh install`。macOS 应用本身没有变化。
