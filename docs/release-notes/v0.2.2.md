Messages reach Claude while it works, background task output is one click away, and the sidebar keeps to current work.

## What changed

- **A message joins the turn under way.** Typed while Claude Code is working, a message goes in at once and the agent sees it after the tool call under way, within the same turn, as when you type into Claude Code itself. While a permission request waits for your answer, and with Codex (which cannot take a message mid-turn), it is queued and goes out when the turn ends.
- **Send now.** Cmd+Enter, or "Send now" on a queued message, stops the turn and sends the message right away.
- **See what a background task printed.** In the Info panel (Cmd+I), click a background command to open the end of its output, followed live while it runs.
- **Why "Allow everything" still asks.** Claude Code runs some safety checks whatever the mode, for example before an `rm -rf` whose target it cannot work out in advance. The request now says that it comes from such a check, with the CLI's reason.
- **Sidebar.** Machines are listed in the order you last used them. Under each, folders untouched for seven days wait behind "more folders".

## Updating

The hub and the runners both need this version: sending into a turn, task output and the reason on a request come from the runner. A machine whose runner is older keeps queueing as before. The macOS app is the same as in 0.2.0 apart from the version number.

运行中的 Claude 也能收到你的消息，后台任务的输出点一下就能看，侧栏只留手头的事。

- **消息并进进行中的这一轮**：Claude Code 工作时发的消息会立刻送过去，助手在手头这次工具调用之后、同一轮里就会看到，和在 Claude Code 里边跑边打字一样。有权限请求在等你确认时，以及 Codex 会话（不能在一轮中途插入消息），消息排队，这一轮结束后发出。
- **立即发送**：⌘回车，或排队消息上的“立即发送”，会停掉这一轮、马上发出。
- **查看后台任务的输出**：在信息面板（⌘I）里点一下后台命令，展开它输出的最后一段，运行中实时刷新。
- **“全部允许”为什么还会问**：Claude Code 有些安全检查不看模式，比如 `rm -rf` 的目标事先算不出来时。现在请求上会注明来自这类检查，并附上命令行给的理由。
- **侧栏**：机器按最近使用的顺序排列；每台机器下，七天没动过的目录收进“还有 N 个目录”。
- **升级**：hub 和 runner 都要换成这一版：插入消息、任务输出、请求的理由都来自 runner。runner 较旧的机器照旧排队。macOS 应用除版本号外与 0.2.0 相同。
