The first release. One page for every Claude Code and Codex session, on every machine you use: read them, search them, and keep working in them.

## Downloads

| File | For |
|---|---|
| `atrium-0.1.0-darwin-arm64.tar.gz` | Mac, Apple silicon |
| `atrium-0.1.0-darwin-amd64.tar.gz` | Mac, Intel |
| `atrium-0.1.0-linux-amd64.tar.gz` | Linux, x86-64 |
| `atrium-0.1.0-linux-arm64.tar.gz` | Linux, ARM |
| `Atrium-0.1.0.dmg` | the macOS app (Apple silicon and Intel) |
| `SHA256SUMS` | checksums of the files above |

Each archive holds the hub, the runner, the install scripts and the docs. Nothing needs compiling.

## Start on one computer

```bash
tar -xzf atrium-0.1.0-darwin-arm64.tar.gz && cd atrium-0.1.0-darwin-arm64
./scripts/local-install.sh install
./scripts/local-install.sh link
```

For several machines, see `docs/install.md` in the archive.

## The macOS app

The app is a window around the page at `http://127.0.0.1:13005`; it needs one of the installs above to show anything. It is **not signed with an Apple Developer ID**, so macOS refuses to open it the first time. Allow it in System Settings → Privacy & Security → "Open Anyway", or run:

```bash
xattr -dr com.apple.quarantine /Applications/Atrium.app
```

## What is in it

- Every session from every machine in one sidebar: machine, working folder, sessions.
- Continue any session, start new ones, pick the model and reasoning effort.
- Fork, edit an earlier message, try again, and a side chat.
- A `/` menu with the agent's own commands.
- Optional terminal and file editor on the session's machine.
- A setup guide that checks each machine live.
- English and Chinese.

## Status

Early. The one-computer install has been run end to end on macOS (Apple silicon); the Linux builds and the server scripts have not been exercised on a clean machine yet. Please report what breaks.
