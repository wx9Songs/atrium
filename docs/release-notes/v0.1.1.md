Signing in on a second device no longer needs a terminal.

## What changed

- **Sign in on another device.** On a device that is already signed in, open ⋯ at the bottom left → "Sign in on another device". It gives you a one-time link (15 minutes, usable once); paste it into the sign-in box on the other device.
- **A clearer sign-in page.** It leads with the above, and explains that the helper command it shows belongs to the computer where Atrium was set up and may not exist elsewhere.
- **A clearer first launch of the macOS app.** If nothing is installed yet, the app now says that it is only a window onto the page and links to the install instructions.
- **Faster recovery after the hub restarts.** Machines report what they can do again within seconds instead of up to ten minutes, and a machine you register shows up in the setup guide right away. (These two were on `main` after 0.1.0 and are in a release for the first time.)

## Updating

- **Hub** (server or one-computer install): replace the `atrium` binary and restart it. On one computer: unpack the new archive and run `./scripts/local-install.sh install` again; your config and sign-in stay.
- **Runners** do not need updating for this release.
- **macOS app**: replace it with the one in `Atrium-0.1.1.dmg`. It is still not signed with an Apple Developer ID; see the README for how to open it.

Downloads are the same set as 0.1.0: one archive per system, the app's `.dmg`, and `SHA256SUMS`.

在第二台设备上登录，不再需要终端。

- **在另一台设备上登录**：在已登录的设备上点左下角 ⋯ →"在另一台设备上登录"，得到一条一次性链接（15 分钟内有效，只能用一次），粘贴到另一台设备登录页的输入框里。
- **登录页说明更清楚**：先讲上面这个办法，并说明页面上那条提示命令是装好 Atrium 的那台电脑上的，别的电脑上可能没有。
- **macOS 应用第一次打开更清楚**：如果还什么都没装，应用会说明它只是页面的一个窗口，并给出安装说明的链接。
- **hub 重启后恢复更快**：机器几秒内重新上报自己的信息（以前最多十分钟）；新登记的机器立刻出现在接入向导里。
- **升级**：hub 换成新的 `atrium` 并重启；单机安装解压新压缩包后再跑一次 `./scripts/local-install.sh install`。runner 这次不用升级。
