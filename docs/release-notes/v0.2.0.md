Atrium 0.2.0 gathers what was added since 0.1.2: notifications you can answer from your phone, an Info panel, attachments, a status bar, and chatting on while background tasks run. It replaces 0.1.3, which went out a few hours earlier with the same features.

## What changed

- **Notifications, answerable where they arrive.** The hub can run a command of yours when a run needs your OK, has answered or failed (a `notify` block in its config), and holds back while an Atrium page is in front of you. With `replies` set, a permission request or a question can be answered from the notification: by writing back, or with buttons if your command draws them. `scripts/notify-feishu.py` does this for Feishu/Lark with cards: Allow / Deny buttons, a question's options as buttons with room for your own answer, a form for several questions or a multi-select. See "Notifications on your phone" in the README.
- **Info panel** (⌘I): how full the session's context is and with what, the background tasks it is running (each can be stopped), the model and the tools and connectors it has. Works for a session at rest too.
- **Keep chatting while background tasks run.** A session whose agent has answered but still has background commands going no longer holds the message box; your next message goes to the same process, and the agent picks up again by itself when a task ends.
- **Attachments.** Paste a picture, drop files or use the paperclip. Files are saved on the session's machine and the agent is told where; pictures are also kept on the hub for a month, so every device shows them.
- **Status bar.** Usage moved from the sidebar to a bar along the bottom: each agent's plan allowance and when it resets, tokens today and over seven days, machines online.
- **Sidebar.** The sessions used last are listed above the machines; a machine can be renamed from its row (the pencil), which changes only the name shown.
- **Reasoning effort** has its own button with a slider, next to the model.
- **Runs survive a restart of the hub.** A turn in flight keeps going on its machine and the hub picks it up again, instead of marking it lost and letting the same session be started twice.
- **Side panel and phones.** The side panel can be resized by dragging its left edge and its tabs stay on one line; on a phone the page can be added to the home screen as an app with its own icon.
- **Running as root.** `"root_sandbox": true` in a machine's `runner.json` lets "Allow everything" work where the runner is root in a throwaway container. Off by default.

## Updating

- **Hub and runners both need this version** for attachments, the Info panel, the status bar's limits and chatting during background tasks. Replace `atrium` on the server and `atrium-runner` on each machine, and restart them; a machine whose runner is older simply does not offer those yet. On one computer: unpack the new archive and run `./scripts/local-install.sh install` again; your config and sign-in stay.
- **Notifications** are off until you add `notify` to the hub's config. A hub installed with `server-install.sh` is kept off the network by its systemd unit, so a command that calls a service needs to run beside it; the Feishu script's header shows how.
- **Since 0.1.3**: the Feishu script no longer drops a form's submit, and keeps its open cards across a restart; the README covers phones and the new features, with new screenshots.
- **macOS app**: `Atrium-0.2.0.dmg` opens a file dialog for the paperclip, which 0.1.2 did not. It is still not signed with an Apple Developer ID; see the README for how to open it.

Downloads are the same set as before: one archive per system, the app's `.dmg`, and `SHA256SUMS`.

Atrium 0.2.0 汇总了 0.1.2 之后加的东西：可以在手机上直接回答的通知、信息面板、附件、状态栏，以及后台任务运行时继续聊天。它取代几小时前发布、功能相同的 0.1.3。

- **通知，并且能在收到的地方回答**：运行需要你确认、已经回复或出错时，hub 可以执行一条你指定的命令（配置里的 `notify`）；你正看着 Atrium 页面时不发。设置了 `replies` 后，权限请求和提问可以直接从通知里回答：回复文字，或者点按钮（如果你的命令画了按钮）。`scripts/notify-feishu.py` 为飞书做好了这一套卡片：允许 / 拒绝按钮，提问的选项按钮加上自己填写的输入框，多个问题用表单。见 README 的“手机通知”。
- **信息面板**（⌘I）：会话的上下文用了多少、都是什么，正在跑的后台任务（可以逐个停止），模型以及可用的工具和连接器。没在运行的会话也能看。
- **后台任务运行时继续聊天**：agent 已经回复、但还有后台命令在跑的会话，不再占住输入框；你的下一条消息发给同一个进程，任务结束时 agent 会自己接着做。
- **附件**：粘贴图片、拖入文件或点回形针。文件保存在会话所在的机器上并告诉 agent 路径；图片还会在 hub 上保留一个月，每台设备都能看到。
- **状态栏**：用量从侧栏移到窗口底部：每个 agent 的套餐额度和重置时间、今天和近七天的 token、在线的机器。
- **侧栏**：最近用过的会话列在机器上方；机器可以在它那一行改名（铅笔按钮），改的只是显示的名字。
- **思考强度**有了单独的按钮和滑块，在模型旁边。
- **hub 重启不再打断运行**：进行中的一轮继续在机器上跑，hub 回来后接着跟踪，不会再标成中断、也不会让同一个会话被启动两次。
- **侧边面板和手机**：侧边面板可以拖动左边缘调整宽度，标签不再换行；在手机上页面可以添加到主屏幕，有自己的图标。
- **以 root 运行**：在机器的 `runner.json` 里加 `"root_sandbox": true`，runner 在一次性容器里以 root 运行时也能用“全部允许”。默认关闭。
- **升级**：附件、信息面板、状态栏额度、后台任务期间聊天，都需要 hub 和 runner 一起换成这一版并重启；runner 较旧的机器只是暂时没有这些功能。通知在 hub 配置里加上 `notify` 之前是关闭的。macOS 应用 `Atrium-0.2.0.dmg` 修好了回形针打不开文件对话框的问题。
- **相比 0.1.3**：飞书脚本不再丢掉表单的提交，重启后仍认得还没回答的卡片；README 补上了手机和新功能的说明，截图换成了新的。
